# WebShield AI

## Project Overview

WebShield AI is a professional web application security platform designed to help website owners identify security weaknesses, monitor website health, and improve overall security.

## Features

- Website Security Scanner
- Security Headers Checker
- SSL/TLS Checker
- Security Score
- Vulnerability Report
- Dashboard
- AI Security Recommendations
- Website Monitoring

## Technology Stack

### Backend
- Python
- FastAPI

### Frontend
- React

### Database
- PostgreSQL

### Scanner
- Nuclei
- OWASP ZAP API
